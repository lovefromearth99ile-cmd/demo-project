# Aurora AI

Aurora is a bilingual AI chat workspace built with Next.js and the OpenAI Responses API.

## Local demo mode (no API credits)

To run the interface without spending OpenAI API credits, add this line to `.env.local`:

```env
AURORA_DEMO_MODE=true
```

Save the file and restart the development server with `npm.cmd run dev` (Windows PowerShell) or `npm run dev` (macOS/Linux). The status badge will show **Demo mode · no API usage**. Demo replies are predefined rule-based samples, not generated by a live AI model.

## Live AI mode

To enable live AI later, set `AURORA_DEMO_MODE=false` and configure a valid `OPENAI_API_KEY` plus approved API billing. API usage is billed separately from ChatGPT. Keep the key only in the local `.env.local` file or the hosting provider's server-side environment settings. Never commit it or share it in screenshots or chat.

## Features

- Responsive chat interface
- English and Bengali sample conversation flow
- Browser-local conversation history (this device only)
- Server-side OpenAI Responses API integration for live mode
- Input and output moderation checks for selected high-risk categories in live mode
- Age-appropriate assistant instructions

## Run locally

1. Install Node.js 20.9+.
2. Open a terminal in the `aurora-ai` folder.
3. Install dependencies: `npm.cmd install` on Windows PowerShell, or `npm install` elsewhere.
4. Create `.env.local` and set `AURORA_DEMO_MODE=true`.
5. Start with `npm.cmd run dev` on Windows PowerShell, or `npm run dev` elsewhere.
6. Visit http://localhost:3000.

## Privacy and architecture

- Demo mode runs predefined code on your computer and makes no API requests.
- Live mode sends messages to the configured OpenAI API. Avoid entering passwords, financial details, private identifiers, or other sensitive information.
- Chat history is saved in the current browser only; there is no cloud database or cross-device memory.
- The separate Adaption dataset and fine-tuning run are not connected to this app yet.
- Moderation and assistant instructions are protective layers, not a guarantee of safety.
- This is a development starter, not a public-ready product. Add authentication, robust server-side rate limiting, and suitable monitoring before public deployment.
